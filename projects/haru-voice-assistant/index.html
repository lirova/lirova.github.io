Haru: bilingual voice assistant

Builder 2026 Used daily Python · FastAPI · phone web app · local speech models
  • Problem: I wanted one hands-free assistant for daily life, in English and Japanese.
  • Built: a FastAPI service with a phone web app. It speaks, keeps the facts I tell it, sets reminders, checks my calendar, and keeps a log of food and workouts.
  • Result: in daily use since October 2026. 194 test files guard it, and it runs on a server I own that is reachable only from my private network.

The problem

I wanted one assistant I could talk to hands-free, in English or Japanese, that remembers what I tell it and runs on hardware I own.

What I built

  • Voice in, voice out. A phone web app records my voice and plays the reply.
  • Memory and reminders. It saves facts I tell it and reminds me at the right time.
  • Daily logs. Food and workouts, logged by talking.
  • Private by design. It runs on my own server and is reachable only on my private network.

Result

I use it every day. 194 test files guard it, so changes don’t break what works.
