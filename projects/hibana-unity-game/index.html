Hibana: 3D anime action game for phones

Solo developer 2026 Unity · C# · Unity Test Framework
  • Problem: my web prototype could not reach the look and feel I wanted on a phone.
  • Built: a Unity port with a fight system, combo moves and views for tuning each character.
  • Result: ported in under a month (October 2026); 70 test files guard the fight and move systems.

The problem

I have made games since I was a kid. My web prototype could not reach the look and feel I wanted for a 3D action game on a phone.

What I built

  • Fight system. Attacks, combos and hit timing.
  • Tuning views. A separate preview for adjusting each character’s moves.
  • Tests. 70 test files guard the fight and move rules.

Result

Ported from the web prototype to Unity in under a month. In active development.
