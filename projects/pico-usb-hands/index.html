USB hands: an AI agent that drives a real PC

Builder 2026 Python · Raspberry Pi Pico · USB HID
  • Problem: I wanted my assistant to use a real PC without installing software on it.
  • Built: a Pico that acts as a USB keyboard and mouse, driven by my assistant.
  • Result: the pass bar came first, with one known-bad case the test was required to catch. It passed 5 of 5 on the real machine once I fixed garbled typing and a mouse conflict.

The problem

I wanted my assistant to operate a real Windows PC, with no software installed on that PC.

What I built

  • A Raspberry Pi Pico that shows up to the PC as an ordinary USB keyboard and mouse.
  • A controller on my server that sends it keystrokes and mouse moves.

How I tested it

Before building I wrote down the pass bar, and added one known-bad case that the test had to catch. The first runs failed twice (garbled typing, a mouse conflict). After both fixes it passed 5 of 5 acceptance cases on the real machine.
